Category: Node.js core · Purpose: Shorten the edit-and-run development loop.
Create a small application run with node --watch. Change an imported module and verify automatic restart; explain the difference between ordinary watch mode and the platform restrictions of --watch-path.

Title "Application Watch Mode". main.mjs: import { message } from './message.mjs'; console.log(message); message.mjs: export const message = 'Hello, Node.js!'; command node --watch main.mjs. Flow Edit imported module → Node restarts process → New output. Show change message to 'Updated!' and illustrative terminal 'Hello, Node.js!' then 'Updated!'. Ordinary --watch monitors entry point and loaded modules on supported platforms; --watch-path sets explicit paths and is limited to macOS/Windows; it disables automatic dependency watching. command node --watch-path=./src src/main.mjs labeled alternate folder layout, macOS/Windows only. Optional node --watch-preserve-output main.mjs. Pitfalls in-memory state resets, top-level side effects rerun; stop Ctrl+C. No npm package needed.
