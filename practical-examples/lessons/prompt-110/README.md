# Prompt 110: Property-based testing

Category: Ecosystem · Purpose: Find edge cases beyond handpicked examples.
Use fast-check to test a binary encoder-decoder round trip. Introduce an endianness or length bug, capture the minimized failing case, and verify the corrected implementation passes.

## Run

From `practical-examples`, install the workspace once with `npm ci`, then run:

```powershell
npm run lesson -- 110
```

Open `demo.mjs` beside this file. Every imported shared helper is supplied in `../../shared/`.

## What students should observe

Generated byte arrays round-trip through the actual codec; the seed makes failures reproducible.

## Walkthrough and experiments

Follow the values through the implementation. Change one input, predict the result, then run again. Assertions intentionally stop the example when its contract is violated.

## Requirements and validation

Execution mode: **automatic**. The catalog and `validation/report.json` distinguish actually executed examples from examples requiring services or native tooling. Expected output above is a teaching target, not an execution claim. Measurements, ports, process IDs, timestamps and generated identifiers vary.
