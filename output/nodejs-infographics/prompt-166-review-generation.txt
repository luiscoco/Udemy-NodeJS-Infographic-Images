Output values must use <measured> placeholders, never invented hardware or memory figures. availableParallelism estimates usable parallelism; do not substitute os.cpus().length as the recommendation. availableMemory returns free bytes available to the process, not total machine RAM. constrainedMemory returns the OS-imposed limit in bytes; 0 means unconstrained or unknown. 128 MiB reserve, 64 MiB per worker and cap 4 are illustrative policy inputs, NOT measured facts or a guaranteed safe configuration. This code only proposes a count; it starts no Workers. workers can be 0 under pressure: defer/reject work rather than force one. Do not confuse a V8 heap limit with an RSS/container limit.
Files (copy exactly):
size-pool.mjs:
import { availableParallelism } from 'node:os';

const availableMiB = Math.floor(process.availableMemory() / 2 ** 20);
const reserveMiB = 128;
const estimatedWorkerMiB = 64;
const cpuSlots = Math.max(1, availableParallelism() - 1);
const memorySlots = Math.floor(
  Math.max(0, availableMiB - reserveMiB) / estimatedWorkerMiB,
);
const workers = Math.min(4, cpuSlots, memorySlots);

console.log({
  availableMiB,
  constrainedBytes: process.constrainedMemory(),
  workers,
});
